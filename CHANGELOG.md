# Release changes

## 1.2.0

- Adds directional LoF analyses, direct FOXP3–TCR and primary Treg–Tconv comparisons, Monaco and ImmGen expression analyses, Perturb-icCITE-seq coverage, and conditional Foxp1 and Sin3a comparisons.
- Includes primary and sensitivity statistics, candidate-level published evidence, and the source values for Figures 1–4, Supplementary Figures S1–S23 and Supplementary Tables S1–S20.
- Organizes the complete code and data by scientific purpose, with one canonical location per identical scientific asset. The validated workflow temporarily restores the earlier release layout when needed for the historical checks.
- Provides archive-only and official-source replay modes, strict figure parity, and a standalone supplementary workbook builder.

## 1.1.0

- Adds expression-restricted, regulator-class and strict joint conditioning, the same-cohort M0–M3 models, LOEUF diagnostics and matching feasibility.
- Adds the 245-gene mechanism master, 104 scoped LoF-compatible genes, 17 cross-screen candidates and published experiment-level evidence including Zhu conventional CD4 results.
- Preserves anonymous whole-blood pair differences and their program summaries, extends the analytical figure source data, and supports independent base-R verification.
