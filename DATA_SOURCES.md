# Data sources

The source manifest records public landing pages, accession identifiers, documented retrieval dates, versions when available, redistribution boundaries, and the role of each source in the released processed tables. It includes GSE212645, the human TF catalog, EpiFactors, MGI orthology, and the GSE90600 gene-span annotation source confirmed from the existing source file.

The Umhoefer source is retained under the accession/publication key `Umhoefer2025` because its electronic publication is in 2025; the Immunity print publication year is 2026.

The release contains derived analysis-ready tables rather than raw source files. The source manifest and dictionaries identify which values are redistributed as derived tables and which source materials remain available only from their public providers.
