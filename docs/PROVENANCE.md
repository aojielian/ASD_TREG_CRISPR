For the optional expression reconstruction, begin with the two processed files deposited at E-GEAD-649. Extract `count_summary.txt` from the archive for DRR500405–DRR500416 and `RNAseq_salmon.merged.gene_counts.tsv` from the archive for DRR500417–DRR500424. Confirm the condition and run labels using the deposited SDRF. The script selects the six NTC libraries for iTreg, excludes the six RBPJ KO libraries, uses four peripheral hTreg and four hTconv libraries separately, and checks the frozen input hashes. Optional HPA validation uses the immune-cell expression TSV from the corresponding historical version. All data retrieval remains manual.

Legacy whole-blood reproductions use paired differences and program summaries. The separate individual-score columns of two historical derivative tables are excluded from this release. The historical source release records remain available at the published version DOI.

The data archive includes author-created processed projections and released source statistics. The repository MIT license applies to code. Independent source terms, copyright and attribution requirements remain applicable. The Zenodo licensing statement applies to the authors' contribution and does not replace upstream terms.

Exact excluded source filenames, digests and retrieval links are in [EXCLUDED_UPSTREAM_INPUTS.tsv](EXCLUDED_UPSTREAM_INPUTS.tsv). The [source rights and access table](SOURCE_RIGHTS_ACCESS.tsv) records attribution and source-specific restrictions by data family. The original provider snapshots are fetched manually and must match the recorded identities before any upstream reconstruction.

## Zhu conventional CD4 candidate context

The v1.1.0 processed release adds cited summary records from Zhu et al., Cell 2026, PMID 42664972. Individual flow and donor-metadata source files are excluded. The accompanying data source inventory preserves the exact eight basenames, byte counts, hashes and URLs. Refer to the [source guide](SOURCES.md) for the separate article and processed dataset rights. [Zhu et al.](https://doi.org/10.1016/j.cell.2026.08.002)
