## Zhu conventional CD4 evidence

The eight recorded source filenames, direct access links, SHA-256 and roles are in `data/r8/zhu_derived/ZHU_SOURCE_FILES.tsv` in the archive. The `ZHU_BIBLIOGRAPHY.tsv` record links the Cell publication, author's figure map and processed v1.0 catalogue. The processed dataset card lists MIT for its catalogued processed data, and the author analysis repository provides a separate code licence. The Cell article is CC BY-NC 4.0. Check the primary source and current source-specific terms when obtaining any original file. The flow CSV is outside the processed dataset card's file list. The companion archive carries cited aggregate evidence, with the original sources and all donor-level records omitted. [Cell article](https://doi.org/10.1016/j.cell.2026.08.002) · [Virtual Cells processed dataset v1.0](https://virtualcellmodels.cziscience.com/dataset/genome-scale-tcell-perturb-seq) · [Author source files](https://github.com/emdann/GWT_perturbseq_analysis_2025/tree/master/metadata)

With the recorded source files obtained under their applicable terms, the [reproduction guide](REPRODUCIBILITY.md) gives the exact extract command. Start at the linked source location and save original bytes, then match the recorded SHA-256 before importing. The script filters the frozen 17-candidate list, retains DE coverage by culture condition, transcribes source-reported arrayed fields and counts unique within-assay flow donor matches. It writes only the compact gene/condition and endpoint summaries. The full processed-data workflow uses the released tables directly.
