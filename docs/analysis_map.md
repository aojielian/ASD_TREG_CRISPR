# Analysis and figure reproduction map

The legacy analysis rows in [analysis_map.tsv](analysis_map.tsv) link the originally released harmonized tables to their reproduction scripts. See the [methods](METHODS_AND_STATISTICS.md) for the current inferential definitions and the [figure source map](FIGURE_SOURCE_MAP.md) for all final renders.

The companion processed package holds full source tables, numerical expectations, generated TSV equivalents of the supplementary workbook, and source reuse and access documentation.
