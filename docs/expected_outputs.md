# Expected outputs

The complete workflow writes source schema and evidence verification, legacy reproduction, R7 recalculated results and numerical verification, and the final vector PDF plus 600 dpi TIFF figures.

The legacy part of the combined workflow writes `legacy/recomputed_core.tsv`, `legacy/recomputed_patient.tsv`, `legacy/expected_results_verification.tsv` and `legacy/independent_reference_checks.tsv`. The original standalone legacy workflow also saves its historical text status files.

Read the [reproduction guide](REPRODUCIBILITY.md) for the expected-value tables, tolerances and command lines.
