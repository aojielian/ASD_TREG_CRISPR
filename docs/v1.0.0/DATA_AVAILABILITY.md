# Data availability

The public GitHub tree contains code, configuration, documentation, manifests, and expected results. Complete processed row-level inputs are deposited in Zenodo under DOI [10.5281/zenodo.22704659](https://doi.org/10.5281/zenodo.22704659) as `ASD_TREG_CRISPR_processed_data_v1.0.0.zip`. The release supports Python 3 standard-library processed-data minimal reproduction of the reported core statistics.

A complete raw-source rebuild is not claimed. Raw and source-derived materials remain subject to the terms and access conditions of their original public providers. See `data/manifests/SOURCE_DATA_MANIFEST.tsv`.
