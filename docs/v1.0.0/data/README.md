# Data layout

The GitHub `data/` directory contains public manifests only. The complete `data/processed/` row-level analysis-ready tables are stored inside the companion Zenodo snapshot under the same relative paths.

`manifests/SOURCE_DATA_MANIFEST.tsv` records source provenance and redistribution boundaries. `DATA_DICTIONARY.tsv` defines the processed tables, and `COLUMN_DICTIONARY.tsv` defines key fields.

The complete processed-data snapshot is archived at Zenodo: [10.5281/zenodo.22704659](https://doi.org/10.5281/zenodo.22704659).
