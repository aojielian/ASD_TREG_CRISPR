# ImmGen ULI methods lock

This lock was written after source and metadata inspection and before candidate expression metrics were computed. Use GSE109125 Gene_count_table_GENCODE_vM25.csv.gz and the accompanying family SOFT. Yoshida et al. (2019) describe young-adult mice and biological duplicate sampling for the published atlas. The repository files are the versions used here and include additional GEO records. See [GEO GSE109125](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE109125), [Yoshida et al.](https://doi.org/10.1016/j.cell.2018.12.036), and [ImmGen sorting documentation](https://www.immgen.org/ImmGenATAC1219Sorts.S1A.pdf).

- Join accession to count-library label by exact SOFT sample title without the final _RNA-seq suffix. Three group-level relabelings are documented in immgen_aliases.tsv. They require matching the source group, phenotype and tissue and the full replicate suffix, unique accession and unique target column. The ImmGen sorting resource confirms aliases for the Ly6C-high and Ly6C-low blood monocytes and CD102-positive F4/80-positive peritoneal macrophages. The sorting resource and GEO descriptions disagree on the small/large size wording for some peritoneal macrophages, so subtype labels use documented gates. Keep MF.PC title aliases distinct from the older MF.PC libraries because their recorded gates differ. Run an exact-title-only sensitivity on the same normalized matrix, excluding all six relabeled libraries. Preserve all SOFT samples, including ones without count columns and their source fields.
- Main comparison groups are independently sorted, mature immune populations with SOFT age reported as 6 weeks and C57BL/6J strain, with no experimental challenge recorded or indicated by label. Retain lineage and tissue differences as descriptive context. Exclude explicitly challenged or induced populations, neonatal-labelled populations, nonimmune stromal cells, progenitors and differentiating thymocyte populations, the P14 antigen-specific transgenic CD8 population, the heparinase-labelled preparation and groups without count columns. Keep germinal-center B cells, plasmablasts, and unsorted-for-maturation thymic iNKT separate from the main analysis because activation/maturation context for these groups is unresolved or differs; include the measured germinal-center B/plasmablast groups only in a labelled separate sensitivity. Retain sorted mature memory and terminal plasma B cells whose records indicate no challenge, retain conventional DX5-positive NK subsets and terminal neutrophils, and keep separately labelled source populations even if tissues or sexes overlap. Sex-specific labels are retained, with no sex inference from unmarked titles. Supplement this comparison with a two-or-more-library filter, a splenic-only subset, and equal weighting of the listed main lineages.
- Treg populations are the author-defined CD25-high splenic Treg and colonic Foxp3-positive Nrp1-low Treg, kept separate. The splenic contrast uses the author-defined splenic CD25-negative naive CD4 group T.4.Nve.Sp, matching tissue and the CD62L-high/CD44-low sort context. The explicitly female naive group and the unsplit bulk CD4 group remain atlas groups. The contrast is descriptive between population medians. Sample suffixes encode replicate indices within each group. Individual animal IDs and cross-group pairing are unavailable. Use one value per unique biological library/BioSample within a group and give all groups equal weight in the primary cross-group metrics. Include single-library groups with their denominator explicit.
- Use the full symbol-level vM25 raw gene count matrix and edgeR TMM library normalization across all available libraries. Positive finite library sizes are required. Take median TMM CPM across each group's available replicates. Ordinary library-size CPM is a sensitivity. Output linear CPM, log2(CPM + 1) and row z-scores using population SD on the logged group values. Constant rows yield undefined z-scores.
- The fixed candidate and reference lists are in immgen_panel.tsv. Ortholog selection uses the frozen MGI HOM_ProteinCoding.rpt. Require uniqueness across both symbols and all IDs and exact match to a vM25 matrix symbol. Preserve unmapped or unmeasured rows as missing. Do not change capitalization to infer mappings. MGI provides mouse symbol, MGI ID, mouse NCBI ID, HGNC ID, human symbol, and human NCBI ID.
- Main breadth is the number and proportion of assessed groups with median TMM CPM >=1. Threshold sensitivities use >=0.5 and >=2. Report the across-group median and linear-scale Tau, with Tau undefined for an all-zero row or fewer than two groups. Rank each Treg against all assessed groups using average ranks for ties, descending so 1 denotes highest. Report midrank percentile = (n - rank)/(n - 1), where 100% denotes highest. Also report log2((splenic Treg CPM + 1)/(splenic naive CD4 CPM + 1)). Equal-lineage sensitivity uses the arithmetic mean of the group medians in each broader lineage and retests only breadth/Tau. Baseline expression estimates are descriptive and species-specific.
