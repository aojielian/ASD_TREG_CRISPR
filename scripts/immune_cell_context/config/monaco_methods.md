# Monaco expression methods

The FOXP3–TCR conditioning methods, GSE107011 sample records and Monaco source methods defined the plan before candidate expression and the detection, rank or matching endpoints were evaluated. Seed 20261125. Human atlas TPM values are separate from all mouse quantities and all perturbation endpoints.

## Source populations and arithmetic

- Primary atlas uses the 29 author-sorted populations from four healthy adult S4 blood donors, with whole-PBMC S13 libraries excluded. GEO titles after removing the deposited replicate suffix must match an exact author description and one TPM column. A donor is identified by the study's prefix, supported by the GEO title replicate suffix. Report the two unavailable CD4 terminal effector donor×type combinations. No absent libraries are imputed.
- The primary conventional CD4 expression contrast averages six author-defined non-Treg populations equally with the same membership for all four donors. They are naive CD4, Tfh, Th1, Th1/Th17, Th17 and Th2. Terminal effector CD4 is included in the 29-type expression analysis and in a separate seven-member conventional CD4 sensitivity limited to the two donors with all seven populations. Primary cell-type TPM contrast is log2((Treg donor-median TPM+1)/(equal mean of the six conventional type donor medians+1)). Also give each donor's Treg TPM, equal-weight conventional TPM and log2 ratio. No donor-level significance test.
- Confirm gene-level TPM from the SOFT data-processing field and versioned ENSG IDs. Match exact IDs to the GENCODE v26 GRCh38 gene feature. Exclude source rows with no gene feature, non-protein-coding biotypes and duplicate Y pseudoautosomal representations confirmed by the corresponding X feature. Never sum across loci with a shared symbol. Use the frozen project HGNC snapshot to link unique stable Ensembl IDs to approved symbols. For exact current-symbol matches with no HGNC stable-ID link, require that the HGNC Ensembl ID field be empty. Ambiguous linkage or disagreements remain disclosed and cannot enter the Chen join. For atlas-only genes use unambiguous GENCODE symbols where no HGNC concordance is available.
- Aggregate median within donor×type across any technical repeats, then median across donors within each type. No abundance or library-size weighting. Compute type-detection breadth at 1 TPM and at predeclared sensitivities 0.5 and 2, median type TPM, linear-scale Tau, and Treg rank with average ties. Treg percentile is (ascending midrank-1)/(types-1), with one representing highest expression. Heatmaps use log2(TPM+1) or the within-gene population-SD z-score of these logged values. Constant rows have undefined z-score, recorded as NA.
- Equal-lineage sensitivity averages within class on linear type TPM and gives each of ten lineages one value. These reflect the nine groups in the original article with Tregs shown separately from conventional CD4. Detection and Tau use those lineage-level values. The same lineage grouping is reused for any compressed display. The four reference genes are fixed examples, positioned after all 14 candidates and without exclusion based on their measured patterns.

## Conditioning and endpoints

- Primary selected-panel contrast is the 14 fixed Chen discovery hits versus non-ASD Chen hits. Supplementary contrast is the frozen 245-gene ASD set versus other Chen-measured genes. Genes must have measured Chen status and a unique protein-coding atlas linkage. Only the full frozen case membership determines the ASD label. Report measured, mapped, complete-case and common-support counts, and separate missingness. Freeze subgroup assignment before computing outcome-dependent statistics.
- Covariates are the FOXP3–TCR primary conditioning attributes, with the class represented by the four frozen TF/EpiFactors classes and exact frozen targeted-library membership. Keep the frozen GSE90600 healthy-CD4 mean logCPM and gnomAD v2.1.1 LOEUF. Add overall atlas expression log2(1+median type TPM over the 29 classes). For each background use ascending midrank tertiles, min(3,ceil(3*rank/n)), in the pooled complete cases, preserving ties. The five-way strata are class, library, healthy-CD4 tertile, LOEUF tertile and atlas expression tertile. No imputation or alternative covariates, bins or calipers.
- Common support requires at least one real ASD and one real non-ASD member per stratum. Retain all such strata and use the observed ASD count per stratum as a fixed margin. Compare the observed case median breadth and Treg percentile with 20,000 random gene sets per population. Sets draw exactly the fixed number of genes from each stratum's combined case/control pool without replacement. This is a conditional gene-label test of exchangeability within strata. Use two-sided empirical tails around the Monte Carlo null median and plus-one P. Apply BH separately to the two endpoints within each population, reserving an unavailable endpoint's slot at one only for adjustment. Provide weighted non-ASD descriptive median and SMD. All these comparisons are exploratory. No gene-label evidence is a donor-level inference or an independent validation of the selected 14 hits.
- Report observed median, difference from the conditional null median, central 95% null interval (the null interval describes draw variation), and descriptive 95% percentile interval for observed minus fixed null median via 20,000 bootstrap resamples of the observed case genes within their strata. The bootstrap interval is conditional on the fixed atlas, matched reference and strata and can be degenerate for saturated endpoints.
- Carry the FOXP3–TCR coverage diagnostics to the matched population, evaluating 80% of frozen cases with comparator support and 70% of complete-case genes in comparator-supported, endpoint-varying strata. These diagnostics qualify interpretation. A missing common support or a degenerate simulated statistic is non-estimable for this contrast. If both coverage diagnostics fail, report the original distributions, matching diagnostics and support-limited null draws while withholding inference. An absolute SMD greater than 0.10 is a residual-imbalance flag, with no redesign, filtering or switch to another method. SMD uses the means with the fixed-stratum control weight and the pooled square root of the two groups' unweighted sample variances. Exact class indicators, library, healthy-CD4 expression, LOEUF and overall atlas expression all receive balance rows.
