# Umhoefer direct screen comparison

The analysis plan used the source structures and FOXP3–TCR comparator methods before fitting the joint comparisons. Confirmatory labels are all 245 HGNC-resolved frozen SFARI score-1 genes from v1.1.0 before intersection with each measured screen. Use the GSE286470 gene and guide workbooks, GEO SOFT, and PMID 41237776 (DOI 10.1016/j.immuni.2025.10.020, Fig. 4 and Methods). No study sources are changed.

## Gate and endpoints

- Join each workbook context and physical Excel row to the frozen measured, unique HGNC identifier. Exclude non-human controls (the pooled `Non-Targeting` row and `EGFP`), and audit all other exclusions, FDR and `num` parity against the preceding release. Both finite MAGeCK FDRs, positive displayed number of guides and a unique human assignment define an evaluable row. Compare the frozen unfiltered individual backgrounds before taking their intersection U. Author hit is the inclusive union of `pos|fdr ≤ 0.05` or `neg|fdr ≤ 0.05` in each screen.
- Preserve the literal `pos|lfc` and `neg|lfc` values and document their parity. In these workbooks the positive selected contrast enriches FOXP3-low bin guides, anchored by the FOXP3 coding-target control and frozen source direction audit. The operational signed effect is minus the workbook `pos|lfc`, so a positive derived value indicates selection toward higher FOXP3 following knockout and a negative value toward lower FOXP3. The effect is a guide-selection gene-summary LFC and has no protein abundance unit.
- The primary estimand is the ASD enrichment OR for Treg-only vs Tconv-only among discordant genes D in U. Report a two-sided Fisher exact P, conditional maximum likelihood OR with two-sided exact 95% CI, and cross-product OR as a named descriptive comparator. Full individual universes and individual screens within U are descriptive using two-sided Fisher tests and conditional exact CIs, with the historical upper-tail P retained for parity. Both/neither and measurement availability counts are explicit.
- Absolute and separately signed effect ranks are ascending average ranks scaled as (rank−1)/(n−1), within U separately by screen. Δrank is Treg minus Tconv. Report mean and median Δrank for ASD/non-ASD and ASD-minus-other differences with gene-level percentile bootstrap 95% intervals (20,000 resamples, fixed observed group sizes). Test the mean difference using 100,000 fixed-size label permutations, two-sided absolute deviations from the zero null expectation and the add-one P with binomial Monte Carlo SE. Signed ranks and both-hit direction agreement are supportive. These are gene-level comparisons of pooled screens.
- Equal-fraction sensitivity screens use k = ceiling(U × fraction), 5%, 10%, 20% separately, retaining all ties at the k-th largest absolute effect. Run the same discordant Fisher test and BH across the three sensitivity thresholds, with non-estimable P set to 1 only for correcting that family.
- Guide coverage and pooled guide-level direction are descriptive. Verify reported counts and experimental unit by SOFT. Donor-level inference or cross-context pairing requires a verified donor crosswalk, independently measurable per-donor effects and appropriate controls. Workbook count vectors do not become additional independent donors or the published donor-level gene statistics.

## Frozen adjustment and uncertainty

Use the direct FOXP3–TCR property set from the v1.1.0 processed inputs. The LoF analyses have their own property set. It consists of the four-level TF/EpiFactors regulator class, targeted-library membership, healthy-CD4 mean logCPM and LOEUF v2.1.1. Use frozen gene attributes on the Umhoefer rows, assert consistency between contexts, report missingness and retain the frozen span and guide coverage in the audit. Define complete cases using the four usable property fields. With U already restricted to the targeted library, membership is expected to be constant and remains in strata; a constant nuisance term is reported and removed only from the Firth design. Set average-rank tertiles of the two continuous variables on all complete-case U, using min(3, ceil(3 × average rank / n)) with ties intact.

1. Within discordant complete cases, condition on both ASD counts and Treg-only counts in each fixed stratum. Sum observed Treg-only ASD counts across strata. Obtain the null by convolution of per-stratum hypergeometric masses. Its two-sided P includes count outcomes at least as far from the null expectation as observed, plus an upper-tail directional P for description. Report observed vs expected counts, count difference, O/E, central 95% null count interval, variance, and support. Zero remaining variance is non-estimable. Report the within-stratum support for both labels and outcome variability separately.
2. Fit the Firth estimator used for the FOXP3–TCR comparison on identical discordant complete-case subsets, once with ASD alone and once with ASD, TF, EpiFactors, standardized healthy-CD4 expression and LOEUF and the library term only if variable. Use two-sided penalized likelihood-ratio P and a 95% profile interval. A deficient/nonconvergent full model stays non-estimable with diagnostics.
3. For continuous Δrank, retain the original ranks defined on U; on property-complete U use strata with both label groups and estimate the case-count-weighted within-stratum ASD-minus-other mean difference. Permute labels within those strata fixing stratum case counts, 100,000 two-sided permutations. Give 95% percentile bootstrap intervals from independently resampling each label within each supported stratum, holding stratum weights fixed. This adjusted estimand is separate from the binary tests. Show raw, complete-case and stratum-supported coverage with before/after SMD calculated using the FOXP3–TCR control weights A/(N−A), weights 1 for ASD genes and pooled unweighted supported variances. Use |SMD|>0.10 as a descriptive residual-imbalance flag.

RNG is NumPy PCG64 with seed 20261125 and distinct child streams for permutations and bootstraps. The primary and each supportive result remain visible. P values in different estimands and screening designs are not interchanged. Donor numbers, stimulation and assay capture are design limits. Comparative ascertainment in the targeted library cannot establish cell or disease specificity.
