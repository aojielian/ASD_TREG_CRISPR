# Figure replay

```sh
bash scripts/release_figures/render.sh DATA OUT --strict-byte-parity --submission-legends
```

Pass the root of the extracted v1.2.0 processed-data archive as `DATA` and a new or empty directory as `OUT`. Use `PYTHON` to select the installed Python interpreter. The renderer reads the frozen plot-level inputs. See the [release guide](../../docs/REPRODUCIBILITY.md).

- Figures 1 and 2 retain the original vector artwork. Figures 3 and 4 are plotted from released numeric sources. All TIFFs are generated by direct 600 dpi rasterization of the corresponding vector PDF and checked pixel by pixel.
- Supplementary Figures S1–S14 retain original vector pages with their complete captions. S15 and S16 preserve their fixed phenotype-comparison and expression artwork, with numbered English captions below it. S17–S23 are plotted from the released data, with their complete English captions below. The renderer builds one PDF with a single supplementary figure per page.
- `inputs.tsv` pins all frozen plotting inputs and artwork. `07_qa/FIGURE_REPLAY_PARITY.tsv` records every generated artifact digest and its frozen reference. `FIGURE_RENDER_QA.tsv` checks full captions, fonts, margins, frozen page pixel agreement, and TIFF density and pixel agreement. `FIGURE_NUMERIC_QA.tsv` records independent numerical checks of the plotted values. `07_qa/rendered_pages/` contains page previews for visual inspection. The renderer also regenerates the scientific legends used in the figures. Add `--submission-legends` to export the separate final editorial main and supplementary legends alongside this render.
- PDF and TIFF bytes can depend on renderer and compression versions even when data and geometry agree. Use `--strict-byte-parity` to require the reported frozen hashes for the generated artifacts, in addition to the immutable source and numeric checks. The current release ran this check with the pinned figure dependencies documented in the repository environment.
